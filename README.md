# Paste Caterpillar — Windows builds

A floating caterpillar on your desktop that remembers recent clipboard text and images. Single portable exe, no install. Data stays next to the exe.

## Download

Get the latest zip from [Releases](https://github.com/wanhkofficial/PasteCaterpillar-releases/releases). Extract to a normal folder (Desktop, Documents, …), then run `PasteCaterpillar.exe`. Do not run from inside the zip.

## What it does

- Copy text or an image → a new body segment grows at the tail
- Click a body ball or its text label → copy that clip again
- Drag a body ball or its text label → paste at the drop point (works across monitors)
- Esc while dragging → cancel paste
- Drag the head → move the worm
- Click the head → open the clip list
- Tray menu → Expand, Clear all, profiles, Export / Import, Settings, Quit

## More you can do

- **Pin** clips (Expand list or right-click) — pinned stay near the head; Clear all keeps pinned
- **Profiles** — add / rename / delete (starts with Work and Personal); separate clip lists
- **Themes** — Garden, Blush, Ocean, Contrast
- **Settings** — UI (size, opacity, spacing, labels, facing, theme, always-on-top, pause, count badge) and Data (profiles, reset position, Clear ALL, Export / Import, data folder)
- **Export / Import** backup (`.pcbak`) — profiles, clips, and UI settings
- File copies become path clips; image copies (including Win+Shift+S) become `[Image]` segments

## Privacy

Watches clipboard text and Ctrl+C / Ctrl+V / Ctrl+Insert / Shift+Insert only. Not a full keylogger. Nothing is uploaded.

## Requirements

Windows 10 / 11 x64.
